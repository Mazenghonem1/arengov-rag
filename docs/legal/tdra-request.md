## English

**To:** [contact address]
**Subject:** Request regarding a non-commercial learning project using public u.ae pages

Dear u.ae team,

My name is Mazen Ghonem, an individual developer. I am building a non-commercial learning project: an Arabic–English assistant that answers questions about visas, Emirates ID, jobs and business setup using public pages on u.ae.

The assistant shows only short snippets with links back to the official u.ae pages and never republishes full pages. The code is public on GitHub, but the page content is not. Every answer carries a disclaimer that it is unofficial, may be outdated and is not official advice, and the project is not affiliated with TDRA or the UAE Government. I crawl slowly (one request every 3 seconds) and identify the crawler in its User-Agent.

Could you please confirm whether this use is acceptable? I will remove the demo and any stored content immediately on request.

Kind regards,
