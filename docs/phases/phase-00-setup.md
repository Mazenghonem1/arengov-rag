## What you should understand after this phase

- **uv project layout:** `pyproject.toml` declares deps, `uv.lock` pins exact versions, and `uv sync --locked` makes CI install exactly what you tested. The `src/` layout stops tests from importing code that isn't installed.
- **`python -m arengov`:** how `__main__.py` makes a package runnable, and how argparse subcommands dispatch with `set_defaults(func=…)`.
- **CI basics:** a workflow is YAML triggered by events (`push`, `pull_request`), and a red check blocks a merge. This is the skeleton the eval gates attach to in phase 15.
- **Why the data never enters git:** copyright (D7). The repo shares code, not TDRA's content.
